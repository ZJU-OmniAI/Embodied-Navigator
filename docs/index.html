01

Abstract

Large vision-language models bring strong visual-semantic understanding to embodied navigation, but their 2D pre-training priors are poorly matched to direct 3D coordinate regression. Dense reasoning schedules add latency, while naive history retention either overflows the context or discards crucial topological information.

TAMP-Nav addresses these limitations in one interaction loop. The policy acts as a visual pointer, selecting a view and 2D pixel that are projected into a 3D waypoint for SLAM execution. It triggers Chain-of-Thought only at critical nodes and stores them as high-fidelity anchors; routine path segments are compressed into Space-Time Indicators. Two-Level GRPO then combines local process rewards with global trajectory outcomes. The resulting RGB-based navigator reaches 66.2% SR on R2R-CE and 65.7% SR on RxR-CE while using selective reasoning on 26.3% of its decisions.

One-sentence contribution. TAMP-Nav aligns where a VLM points, when it thinks, what it remembers, and how its decisions receive feedback.

02

Method

Four aligned components connect high-level visual reasoning to efficient long-horizon execution.

P

Point

Select one of four RGB views and a 2D pixel waypoint. Depth is used only afterward to project the prediction into 3D for the SLAM controller.

Aligns action prediction with 2D visual priors.

T

Think

Trigger explicit Chain-of-Thought at difficult topological nodes instead of reasoning densely or at fixed intervals.

Allocates computation to consequential decisions.

M

Memorize

Retain critical states as visual-reasoning anchors and encode routine motion with lightweight Space-Time Indicators.

Preserves topology without storing every frame.

A

Align

Superimpose local action advantages and global trajectory advantages across multi-branch Two-Level GRPO rollouts.

Bridges immediate decisions and final success.

Local process feedback

Which decision works here?

Target approach, collision avoidance, stop correctness, reasoning value, and output validity provide dense feedback at each state.

Global outcome feedback

Did the full plan work?

Task success, path efficiency, and reasoning density evaluate complete trajectories and discourage unnecessary computation.
